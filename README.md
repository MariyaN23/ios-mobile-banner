# 📱 Mobile Banner for iOS 📱

## Application Description

Full-screen banner for iPhones in portrait orientation to display in WebView. \
Available in 6 languages (German, English, Spanish, French, Japanese, Portuguese). \
English is set by default and languages switch in query string with two-letter language code (?lang=[lang]) \
Link on deployed project: https://curious-cascaron-096889.netlify.app/?lang=en

## Tools
- HTML
- CSS
- native JavaScript
